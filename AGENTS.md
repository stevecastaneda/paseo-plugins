# Paseo plugins

Plugin API. Before changing a contribution, the client/server split, an RPC, the manifest, or install/reload, verify capabilities in the installed Paseo implementation first. Use the local source checkout at `~/github/repos/paseo` to trace behavior, checking that the relevant code matches the installed version. Then use https://paseo.sh/docs/plugins/v0.8 as a second confirmation. If source or docs disagree with the installed implementation, target the installed behavior and call out the mismatch.
